# 交互记录卡片布局故障示意 Demo

这是一个可删除的独立调试 Demo，不属于生产前端，也不依赖后端、构建工具或第三方库。

直接打开 `index.html`，点击“播放到 20 条”即可观察：

1. 前 10 条项目 Notice 先进入旧版固定 10 行 Grid，看起来暂时正常；
2. 第 11 条开始，协议记录进入 Grid 隐式行；
3. 旧版前 10 个显式行被压缩，卡片高度接近现场的 14px；
4. 修复版使用纵向 Flex，卡片保持最小高度，超出固定视口后滚动。

滑块可以停在任意记录数量，便于对照“问题出现前”和“问题出现后”。“显示旧版 10 行轨道”可以打开或关闭旧版 Grid 的示意线。
